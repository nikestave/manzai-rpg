# ドット漫才 〜目指せ笑王グランプリ〜 企画書 v0.1

## コンセプト
売れない若手コンビを育て、年に一度の漫才大会「笑王（しょうおう）グランプリ」優勝を目指す育成シミュレーション。
比重は **育成 7 : 漫才バトル 3**。スマホ縦画面・片手操作で遊べるWebアプリ。

## 権利方針（B案）
- 実在芸人は「芸風」だけをモチーフにした架空コンビにする（名前・外見・決め台詞は流用しない）
- 大会名は架空（笑王グランプリ）。「M-1」は使わない
- 審査員も実在人物ではなく役割名（上方の重鎮、元王者 など）

## 選べるコンビ（難易度＝残り年数）
| コンビ | モチーフの芸風 | 開始 | 得意な伸び |
|---|---|---|---|
| スターダスト急行 | 動き回る天才ボケ × 早口たとえツッコミ（若き新星） | 結成1年目 | ボケ・華 |
| メトロポリス | 毒舌でやさぐれたツッコミ | 結成3年目 | ツッコミ・メンタル |
| ネバーモア | 淡々と狂っていくボケ（技巧派しゃべくり） | 結成5年目 | 間・ネタ |
| ラジオスター | 堂々とズレた漫才（遅咲き・不仲から） | 結成8年目 | 華・コンビ仲 |

出場資格は結成15年目まで。それを過ぎるとゲーム終了。

## 1年の流れ（全16ターン、半月で1ターン）
```
4月前半 …… 8月後半[1回戦] 9月後半[2回戦] 10月後半[3回戦] 11月前半[準々決勝] 11月後半[準決勝] → 12月 決勝
```
- 予選は育成の途中に挟まる。負けても残りのターンは育成を続けられる
- 年末に体力全回復 → 翌年へ

## 育成（メイン）
**ステータス**（0〜100、G〜Sランク）：ボケ / ツッコミ / ネタ / 間 / 華 / メンタル / コンビ仲
**リソース**：体力、所持金、人気

| 行動 | 主な伸び | 備考 |
|---|---|---|
| ネタ作り | ネタ・ボケ | 時々「新ネタカード」を獲得 |
| ネタ合わせ | 間・コンビ仲 | |
| ボケ特訓 / ツッコミ特訓 | ボケ / ツッコミ | |
| 劇場出番 | 華・メンタル・間・人気 | ギャラが入る（人気で増える）。ウケ・スベリ判定あり |
| バイト | お金 | |
| 飲み会 | コンビ仲・体力少し回復 | お金を使う |
| 休む | 体力回復 | |

- **練習レベル**：同じ行動を4回するとLvアップ（最大Lv5）。伸びが+20%ずつ増える
- **体力が30未満**だと失敗率が上がる（失敗すると伸びが小さく、メンタルが下がる）
- **生活費**：毎ターン3万円かかる。お金がマイナスだとメンタルとコンビ仲が下がる
- **ランダムイベント**：約30%の確率で発生し、選択肢がある。コンビ専用イベントでは奥義カードが手に入る
- コンビ仲が20未満になると「解散危機」イベントが起きる

## 漫才バトル（サブ）
- 4つの局面（つかみ → 展開 → 盛り上がり → オチ）ごとに、ネタ帳から引いた3枚のうち1枚を選ぶ
- ゲージの初期値は「ネタ」ステータスで決まり、4枚の点数を加えた合計が予選の通過ラインを超えれば勝ち
- カードの点数 = 基礎値 × (0.5 + 対応ステータス/100) × 局面補正 × 各種補正
  - ボケのあとにツッコミを出す：×1.25（コンボ）
  - 同じ種類のカードを続ける：×0.85
  - 天丼：それまでに出したボケの数だけ加点
  - 伏線回収：オチで出すと×2
  - つかみ系：つかみで出すと×1.6
  - 間を溜める：次のカードが×1.4
- 決勝：ライバル9組と得点を競い、上位3組に入れば最終決戦。最終決戦は審査員5人の投票で決まる

## ドット絵
- キャラは16×20ドットの2頭身。髪型・髪色・服の色・メガネの組み合わせをコードで生成する（後から手描きのドット絵に差し替え可能）
- フォントは DotGothic16
